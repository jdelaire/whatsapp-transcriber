## Recorded validation

Before the release rebuild, 82 Python tests and 26 Swift tests passed. Actual on-device model probes passed for English, French, a long transcript and a long chunked transcript. These checks were prior validation, not tests of the final native UI or an installed upgrade.

The final notarized archive passed isolated packaged-engine checks for initialization, an original larger than 1 MiB, claim/check/finish, empty claims, caching while summaries were off, snapshots and preservation of the original. It preserved all 1,664,021 original UTF-8 bytes. The packaged engine reported version 1.2.0, build 3.

The source archive passed CRC validation. All 18 Swift sources and the summary module matched the release source byte for byte. Sparkle's license matched. Source-material checks found no private home or project paths, private release key material, build directories or credential directories. Pinned upstream cryptographic test fixtures were retained as third-party source.

## Installed Sparkle upgrade

System logs confirm a real upgrade from the observed 1.1.0, build 2 installation to 1.2.0, build 3 on November 6, 2026. At 13:37:25 UTC, the old app completed its download successfully. At 13:37:26, Sparkle Autoupdate validated the archive's EdDSA signature. At 13:37:29, the old app exited voluntarily, the installer exited successfully and Sparkle relaunched the new app. The old app, engine and receiver processes were gone afterward.

The installed app matched all 443 entries in the verified published archive, including 11 symlinks, with no extra files. Its strict signature and stapled ticket validated. Read-only status reported the linked account authenticated and connected, capture unpaused, the speech model ready and the worker alive. The completed job count remained one, and one saved summary was ready.

The UI trigger and installation clicks were not observed. Installation success is established by the signature, installer and relaunch records together with the installed bundle comparison. No personal transcript body was read during the audit. Original transcript bytes could not be compared without a baseline hash, and a fresh incoming voice note was not tested. Detailed local evidence is retained under `.build/sparkle-1.2.0-upgrade/audit.json` and `audit.md`; the earlier precondition-change report remains intact.

## Limits

- Transcription requires Apple Silicon and macOS 15 or later. The final app and engine declare macOS 15.0; Foundation Models is weak-linked. Summary generation requires macOS 26 or later with Apple Intelligence and its model ready.
- Actual execution on macOS 15 remains untested.
- The terminal release task did not test the final native UI.
- The installed upgrade is confirmed by system evidence above; its UI steps were not observed or recorded.
- The recorded release checks used no personal store and did not download a model.
